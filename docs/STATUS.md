## Что важно знать новой сессии
- **В облачной сессии** `git push` работает только в ветку этой сессии. Поэтому одна сессия = одна ветка = один PR. Смерженный PR не переиспользуется.
- **Решения ВП** записаны в `discovery.md` (с датой и кодом решения) и в журнале изменений `requirements/README.md` §10. Перед изменением требований проверь, нет ли уже решения.
- **Документы для ВП** пишутся по-русски. Вопросы к ВП — нумерованным списком с вариантами и рекомендацией.
- **Подписка на события PR** привязана к сессии. Чтобы следить за PR из новой сессии, подпишись заново.
