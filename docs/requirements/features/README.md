## Как читать файл фичи
- User story называет право, а не роль: «Как пользователь с правом «Экспорт реестра»…». Роли настраиваются (README §5), а роли по умолчанию с этим правом перечислены в таблице §2 файла [ревью ВП 2026-10-14]. Так же записан шаблон `.claude/skills/analyst/templates/feature.md`.
- `F-NN.USm` — user story, `F-NN.BRk` — бизнес-правило. Ссылка на правило другой фичи — полным ID, например `F-01.BR23`.
- В квадратных скобках — источник правила: `[S1 ¶N]`, решение ВП, `INV-n`, раздел доменной модели.
- `[PROPOSAL]` — предложение Аналитика без источника: ВП утверждает его вместе с порцией.
- `[B2-Nx]` — правило следует решению ВП по вопросу N порции 2 (таблица выше).
- `[B3-Nx]` — правило следует решению ВП по вопросу N порции 3.
